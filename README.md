🧵 Strings & Statutes (or project title)
"The strings are tight, the stage is dark, and the Puppet Master is watching your every move."

A psychological survival-horror game developed as part of a university capstone project. Built using Unity for rendering, audio management, and scene design, coupled with a custom C++ backend/plugin architecture.

📖 About the Project
Strings & Statutes is a first-person horror game set inside a decaying, Victorian-era marionette workshop. Players take on the role of a trapped artisan who must solve environmental puzzles while evading autonomous, life-sized wooden puppets controlled remotely by an unseen "Puppet Master."

Unity (C#): Handles the game loop, user interface, audio occlusion, environment layout, and rendering pipelines.

C++ Core / Native Plugin: Manages high-performance mathematical computations, custom physics tension calculations for puppet strings, and behavior tree evaluations for the stalker AI.
